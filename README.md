# Mi Portafolio Personal — Melany Alejandra Arcos Lomas

**Estudiante:** Melany Alejandra Arcos Lomas  
**Actividad:** Actividad Integradora 1: Desarrollo de un portafolio personal.

## Descripción
Sitio web personal que presenta mi perfil, formación académica, habilidades, trayectoria, proyectos y una sección de contacto.

## Tecnologías
- HTML5 (etiquetas semánticas)
- CSS3 (variables CSS, Flexbox, Grid, pseudoclase `:hover`)
- Git y GitHub para control de versiones

## Cómo visualizar
1. Descarga o clona este repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en un navegador (Chrome, Edge o Firefox).
4. No es necesario instalar dependencias.

## Estructura
- `index.html`: contenido de la página
- `styles.css`: estilos externos
- `img/`: fotografía e ilustraciones de los proyectos
- `README.md`: documentación
